79. 单词搜索

题目

描述：

给定一个 m x n 二维字符网格 board 和一个字符串单词 word。如果 word 存在于网格中，返回 true；否则，返回 false。

单词必须按照字母顺序，通过相邻的单元格内的字母构成，其中“相邻”单元格是那些水平相邻或垂直相邻的单元格。同一个单元格内的字母不允许被重复使用。

示例 1:

  • 输入: board = [['A','B','C','E'],['S','F','C','S'],['A','D','E','E']], word = "ABCCED"
  • 输出: true示例 2:

  • 输入: board = [['A','B','C','E'],['S','F','C','S'],['A','D','E','E']], word = "SEE"
  • 输出: true示例 3:

  • 输入: board = [['A','B','C','E'],['S','F','C','S'],['A','D','E','E']], word = "ABCB"

  • 输出: false提示:

  • m == board.length
  • n = board[i].length
  • 1 <= m, n <= 6
  • 1 <= word.length <= 15
  • board 和 word 仅由大小写英文字母组成

进阶： 你可以使用搜索剪枝的技术来优化解决方案，使其在 board 更大的情况下可以更快解决问题？

题解

先排除字符数量不足的情况

单词路径只能沿上下左右移动，同一格在一条路径中最多使用一次。若棋盘格数少于词长，直接失败；再统计棋盘和单词的字符频次，只要某种字符的需求超过库存，也直接失败。字符数量足够只是必要条件，还要检查位置能否连成路径。

代码使用长度为 128 的计数数组，覆盖题目中的英文字母。如果单词首字符在棋盘中比末字符更常见，就反转单词，从更稀少的一端开始搜索。上下左右的连接是双向的，一条路径反向走仍合法，所以这项优化不会改变答案。

逐个匹配字符并限制重复使用

dfs(board, word, i, j, k) 尝试用格子 (i,j) 匹配第 k 个字符。越界或字符不同就返回 false；当前字符相同且 k 已是最后一个下标时，说明整词匹配成功。

否则先保存当前字符，将格子改成 \0，再向四个方向匹配 k + 1。临时标记不会等于题目中的英文字母，因此同一条递归路径无法重新使用该格。四个方向用 || 连接，一条分支成功即可停止其他尝试。

例如棋盘只有相邻的 A、B 两格时，不能通过 A → B → A 匹配 ABA，因为最后一步会重复使用起点。这里需要的是“当前路径已访问”，不能永久标记整块棋盘，否则会阻止其他起点的合法搜索。

成功返回前也要恢复棋盘

代码先把四方向搜索结果保存到 found，再恢复格子，最后返回结果。因此无论本次分支成功还是失败，调用后棋盘都会恢复原样。若在递归成功时直接提前返回而跳过恢复，可能留下临时标记。

设棋盘为 $m×n$、词长为 $L$。预检查需要 $O(mn+L)$ 时间；通过检查后，从每个起点搜索，首步最多有 4 个方向，之后不能回到前一格，最坏时间为 $O(mn×3^{L-1})$，辅助空间为 $O(L)$，主要来自递归栈及单词字符数组。

import java.util.*;

public class Main {

    public static boolean exist(char[][] board, String word) {
        int m = board.length;
        int n = board[0].length;

        if (m * n < word.length()) {
            return false;
        }

        int[] boardCounts = new int[128];
        for (char[] row : board) {
            for (char c : row) {
                boardCounts[c]++;
            }
        }

        char[] wordChars = word.toCharArray();
        int[] wordCounts = new int[128];
        for (char c : wordChars) {
            wordCounts[c]++;
            if (wordCounts[c] > boardCounts[c]) {
                return false;
            }
        }

        if (boardCounts[wordChars[0]] > boardCounts[wordChars[word.length() - 1]]) {
            word = new StringBuilder(word).reverse().toString();
            wordChars = word.toCharArray();
        }

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] == wordChars[0] && dfs(board, wordChars, i, j, 0)) {
                    return true;
                }
            }
        }

        return false;
    }

    private static boolean dfs(char[][] board, char[] word, int i, int j, int k) {
        if (i < 0 || i >= board.length || j < 0 || j >= board[0].length) {
            return false;
        }

        if (board[i][j] != word[k]) {
            return false;
        }

        if (k == word.length - 1) {
            return true;
        }

        char temp = board[i][j];
        board[i][j] = '\0';

        boolean found = dfs(board, word, i + 1, j, k + 1) ||
                        dfs(board, word, i - 1, j, k + 1) ||
                        dfs(board, word, i, j + 1, k + 1) ||
                        dfs(board, word, i, j - 1, k + 1);

        board[i][j] = temp;
        return found;
    }

    public static void main(String[] args) {
        char[][] board1 = {
            {'A','B','C','E'},
            {'S','F','C','S'},
            {'A','D','E','E'}
        };
        String word1 = "ABCCED";
        System.out.println("示例 1 输入: board = " + Arrays.deepToString(board1) + ", word = " + word1);
        System.out.println("示例 1 输出: " + exist(board1, word1));
        System.out.println("-----------------------------");

        char[][] board2 = {
            {'A','B','C','E'},
            {'S','F','C','S'},
            {'A','D','E','E'}
        };
        String word2 = "SEE";
        System.out.println("示例 2 输入: board = " + Arrays.deepToString(board2) + ", word = " + word2);
        System.out.println("示例 2 输出: " + exist(board2, word2));
        System.out.println("-----------------------------");

        char[][] board3 = {
            {'A','B','C','E'},
            {'S','F','C','S'},
            {'A','D','E','E'}
        };
        String word3 = "ABCB";
        System.out.println("示例 3 输入: board = " + Arrays.deepToString(board3) + ", word = " + word3);
        System.out.println("示例 3 输出: " + exist(board3, word3));
    }
}
