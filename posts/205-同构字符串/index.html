205. 同构字符串
205. 同构字符串

题目

描述：

给定两个字符串 s 和 t ，判断它们是否是同构的。

如果 s 中的字符可以按某种映射关系替换得到 t ，那么这两个字符串是同构的。

每个出现的字符都应当映射到另一个字符，同时不改变字符的顺序。不同字符不能映射到同一个字符上，相同字符只能映射到同一个字符上，字符可以映射到自己本身。

示例 1:

  • 输入: s = "egg", t = "add"
  • 输出: true

示例 2:

  • 输入: s = "foo", t = "bar"
  • 输出: false

示例 3:

  • 输入: s = "paper", t = "title"
  • 输出: true

提示:

  • 1 <= s.length <= 5 * 10^4
  • t.length == s.length
  • s 和 t 由任意有效的 ASCII 字符组成

题解

一一映射等价于相同的重复模式

同构要求 s 中同一个字符始终对应 t 中同一个字符，并且不同字符不能对应到同一个字符。字符可以映射到自身。比如 egg 和 add 都是“新字符、新字符、重复第二个字符”，可以对应；foo 和 bar 则不能对应，因为两个 o 被要求分别对应 a 和 r。

可以直接维护双向映射，也可以记录每个字符上一次出现的位置：处理下标 i 时，如果 s[i] 与 t[i] 的历史出现模式一致，它们上一次出现的位置必然相同；若一个从未出现、另一个出现过，或二者上次出现的位置不同，就发生映射冲突。

用下标加一表示出现位置

两个数组初始全为 0，用 0 表示从未出现，实际位置保存为 i + 1。如果直接保存 i，下标 0 的出现记录就会与“未出现”混淆。每一步先比较旧记录，相等后再同时写入 i + 1。

以 egg 和 add 为例：第一对 e/a 的旧记录都是 0，更新为 1；第二对 g/d 也都未出现，更新为 2；第三对 g/d 的旧记录同为 2，仍合法。而 ab 与 aa 到第二对时，b 的旧记录为 0、a 为 1，立即发现两个不同字符试图对应同一字符。

题目保证两串等长且字符属于 ASCII，长度为 256 的数组足以覆盖下标范围。若扩展到其他字符集，应重新选择记录结构，不能直接将任意字符作为当前数组的下标。

public boolean isIsomorphic(String s, String t) {
    int[] mapS = new int[256];
    int[] mapT = new int[256];

    for (int i = 0; i < s.length(); i++) {
        char c1 = s.charAt(i);
        char c2 = t.charAt(i);

        if (mapS[c1] != mapT[c2]) {
            return false;
        }

        mapS[c1] = i + 1;
        mapT[c2] = i + 1;
    }

    return true;
}

时间复杂度是 O(n)，因为只遍历了一遍字符串；空间复杂度是 O(1)，因为数组大小固定。

public class Main {

    public static boolean isIsomorphic(String s, String t) {
        if (s.length() != t.length()) {
            return false;
        }

        int[] mapS = new int[256];
        int[] mapT = new int[256];

        for (int i = 0; i < s.length(); i++) {
            char c1 = s.charAt(i);
            char c2 = t.charAt(i);

            if (mapS[c1] != mapT[c2]) {
                return false;
            }

            mapS[c1] = i + 1;
            mapT[c2] = i + 1;
        }

        return true;
    }

    public static void main(String[] args) {
        String s1 = "egg";
        String t1 = "add";
        System.out.println("示例 1 输入: s = \"" + s1 + "\", t = \"" + t1 + "\"");
        System.out.println("示例 1 输出: " + isIsomorphic(s1, t1));
        System.out.println("-----------------------------");

        String s2 = "foo";
        String t2 = "bar";
        System.out.println("示例 2 输入: s = \"" + s2 + "\", t = \"" + t2 + "\"");
        System.out.println("示例 2 输出: " + isIsomorphic(s2, t2));
        System.out.println("-----------------------------");

        String s3 = "paper";
        String t3 = "title";
        System.out.println("示例 3 输入: s = \"" + s3 + "\", t = \"" + t3 + "\"");
        System.out.println("示例 3 输出: " + isIsomorphic(s3, t3));
    }
}
