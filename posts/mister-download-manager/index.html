Mister Download Manager：免费开源的下载管理器，支持视频、BT 和多线程下载

Mister Download Manager：免费开源的下载管理器，支持视频、BT 和多线程下载

平时下载软件、压缩包或者大文件，浏览器自带的下载功能往往不够方便。想下载网页视频、批量保存图片或者使用磁力链接，又得寻找不同的工具。

最近看到一个不错的开源项目：Mister Download Manager（MDM）。

它是一款类似 IDM（Internet Download Manager）的下载管理器，支持 Windows、macOS 和 Linux，提供简体中文界面，完全免费、开源、无广告。

除了普通文件下载，它还集成了视频下载、BT 下载、浏览器接管、批量图片下载等功能，甚至支持通过 AI 助手管理下载任务。

一、主要功能

1. 多线程下载与断点续传

MDM 支持 HTTP、HTTPS、FTP 等常见下载协议，可以通过多连接分段下载提高大文件的下载效率。

下载过程中可以随时暂停和恢复。如果网络突然中断，只要下载源支持断点续传，就能继续下载已有的部分，不用重新开始。

软件还提供实时下载速度、剩余时间、连接状态等信息，方便查看下载进度。

2. 浏览器下载接管

MDM 提供浏览器扩展，支持 Chrome、Edge、Firefox、Brave、Opera 等浏览器。

安装扩展并连接桌面程序后，平时在浏览器中点击下载链接，就可以直接交给 MDM 处理，不用每次手动复制地址。

它还支持识别网页中的部分视频和音频资源，可以直接从浏览器选择需要下载的内容。

3. 在线视频下载

MDM 的视频下载功能借助 yt-dlp 和 ffmpeg 实现，支持多个视频网站，例如：

  • YouTube
  • TikTok
  • Vimeo
  • Twitch
  • Instagram
  • Facebook

解析视频页面后，可以选择清晰度、字幕等内容，还支持部分视频网站的播放列表批量下载。首次使用时需要准备辅助工具，具体步骤见下文。

4. BT 种子与磁力下载

除了普通文件，MDM 还支持 .torrent 文件和 Magnet 磁力链接。

直接添加种子文件或磁力链接，就可以创建下载任务。

对于包含多个文件的种子，还可以选择需要下载的文件，不必将整个资源全部下载下来。

BT 下载同样支持任务暂停、恢复、进度查看和做种。

5. 批量图片下载

MDM 可以借助 gallery-dl 下载受支持网站上的图片合集、相册和画廊。

例如，需要保存某个相册中的大量图片时，可以直接输入对应的页面地址，由工具批量处理，省去逐张右键保存的操作。

6. 下载队列与定时任务

当需要同时下载大量文件时，可以通过 MDM 统一管理：

  • 下载队列：将多个文件加入队列，按计划执行。
  • 定时下载：指定下载任务的执行时间。
  • 速度限制：控制单个任务或所有任务的下载速度。
  • 文件分类：按视频、音乐、文档等类型分类保存。
  • 批量管理：集中暂停、恢复或删除下载任务。

此外，MDM 还支持局域网远程控制。比如电脑或 NAS 上运行着下载器，可以通过手机浏览器查看进度、添加链接和管理任务。

二、如何下载安装？

项目的所有安装包都可以从 GitHub Releases 获取。

下载地址： https://github.com/anefzaoui/misterdownloadmanager/releases/latest

根据操作系统选择对应文件：

操作系统安装包
Windows...-setup.exe
macOS（Apple Silicon）...-macos-arm64-experimental.dmg
macOS（Intel）...-macos-x86_64-experimental.dmg
Ubuntu / Debian...-linux-x86_64.deb
Fedora / openSUSE...-linux-x86_64.rpm
其他 Linux...-linux-x86_64.AppImage

macOS 安装包标有 experimental。项目 README 说明这些构建尚未经过维护方的 Mac 实机测试；Mac 用户试用时应先确认所需功能能否正常运行。

下载安装后，首次打开软件可以选择简体中文，也可以在菜单栏的 View → Language 中切换语言。

三、如何使用？

1. 下载普通文件

打开 MDM，点击工具栏中的「添加 URL」，粘贴文件的下载链接。

选择保存位置后，点击开始下载即可。

下载过程中可以查看实时速度、文件大小和预计剩余时间，也可以随时暂停、恢复或调整限速。

2. 下载网页视频

首次使用时，先按照软件提示安装 yt-dlp 和 ffmpeg 辅助工具。准备完成后，再复制视频页面地址，在 MDM 中选择「添加 URL」或视频下载功能。

软件解析成功后，选择需要的清晰度和保存位置，开始下载。

3. 下载 BT 资源

点击「添加 Torrent」，选择本地 .torrent 文件，或者粘贴 Magnet 磁力链接。

等待软件读取资源信息后，勾选需要下载的文件，选择保存目录并开始下载。

4. 让浏览器自动接管下载

如果经常使用浏览器下载文件，建议安装 MDM 对应的扩展：

  • Chrome / Edge / Brave 扩展
  • Firefox 扩展

安装扩展并完成与 MDM 的连接后，在网页中点击文件下载链接，就可以直接交给 MDM 下载。

四、AI 与自动化支持

MDM 还有一个比较有意思的功能：内置 MCP Server，可以连接 Claude Code、Cursor 等支持 MCP 的 AI 工具。

让 MDM 保持运行，在 AI 客户端中配置随软件提供的 MCP Server；查询和管理已有任务还需要启用 MDM 的自动化 API。程序路径、客户端配置和启用方法见官方 MCP 接入说明。

例如：

帮我下载这个文件，保存到 Downloads 文件夹。

查看当前所有正在下载的任务。

暂停全部下载，稍后再继续。

清理已完成的下载记录，但保留本地文件。

此外，MDM 还提供独立的命令行工具，并支持无界面运行，可以部署在 Linux 服务器、Docker 或 NAS 上。

对于喜欢折腾自动化的用户，这些功能也很实用。

五、项目地址

对于经常下载大文件、保存视频素材，或者想找一款免费 IDM 替代工具的用户，可以试试。

  • GitHub： https://github.com/anefzaoui/misterdownloadmanager
  • 官方网站： https://misterdownloadmanager.com
  • 软件下载： https://github.com/anefzaoui/misterdownloadmanager/releases/latest
