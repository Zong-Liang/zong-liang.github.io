74. 搜索二维矩阵

题目

描述：

给你一个满足下列两条属性的 m x n 整数矩阵：

  • 每行中的整数从左到右按非严格递增顺序排列。
  • 每行的第一个整数大于前一行的最后一个整数。

给你一个整数 target，如果 target 在矩阵中，返回 true；否则，返回 false。

示例 1:

  • 输入: matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 3
  • 输出: true示例 2:

  • 输入: matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 13

  • 输出: false提示:

  • m == matrix.length
  • n == matrix[i].length
  • 1 <= m, n <= 100
  • -10^4 <= matrix[i][j], target <= 10^4

题解

这题的关键在题目给的两个有序条件：行内递增、下一行首元素大于上一行尾元素。把这两条放在一起看，矩阵其实等价于一个整体有序的一维数组。

所以做法不是“二维里折腾路径”，而是直接一维二分。把总长度记成 m * n，二分下标 mid 后，用 mid / n 和 mid % n 映射回矩阵坐标，再和 target 比较并收缩区间。

这种映射做熟以后会很稳：mid 只负责“第几个元素”，除法和取模负责“在哪一行哪一列”。算法主体仍然是你熟悉的二分模板。

import java.util.Arrays;

public class Main {

    public static boolean searchMatrix(int[][] matrix, int target) {
        if (matrix == null || matrix.length == 0) {
            return false;
        }

        int m = matrix.length;
        int n = matrix[0].length;

        int left = 0;
        int right = m * n - 1;

        while (left <= right) {
            int mid = left + (right - left) / 2;

            int row = mid / n;
            int col = mid % n;
            int midVal = matrix[row][col];

            if (midVal == target) {
                return true;
            } else if (midVal < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }

        return false;
    }

    public static void main(String[] args) {
        int[][] matrix1 = {
            {1, 3, 5, 7},
            {10, 11, 16, 20},
            {23, 30, 34, 60}
        };
        int target1 = 3;

        System.out.println("示例 1 输入:");
        System.out.println("matrix = " + Arrays.deepToString(matrix1));
        System.out.println("target = " + target1);
        System.out.println("示例 1 输出: " + searchMatrix(matrix1, target1));
        System.out.println("-----------------------------");

        int[][] matrix2 = {
            {1, 3, 5, 7},
            {10, 11, 16, 20},
            {23, 30, 34, 60}
        };
        int target2 = 13;

        System.out.println("示例 2 输入:");
        System.out.println("matrix = " + Arrays.deepToString(matrix2));
        System.out.println("target = " + target2);
        System.out.println("示例 2 输出: " + searchMatrix(matrix2, target2));
    }
}

复杂度分析：时间复杂度 O(log(mn))，空间复杂度 O(1)。

这题的迁移点在于“降维思考”：只要全局有序，外表是二维也能按一维处理。
