题目

描述：

给你一个 非严格递增排列 的数组 nums ，请你 原地 删除重复出现的元素，使每个元素 只出现一次 ，返回删除后数组的新长度。元素的 相对顺序 应该保持 一致 。然后返回 nums 中唯一元素的个数。

考虑 nums 的唯一元素的数量为 k，去重后，返回 k。nums 的前 k 个元素应包含排序后的唯一数字。下标 k-1 之后的剩余元素可以忽略。

示例 1:

  • 输入: nums = [1,1,2]
  • 输出: 2, nums = [1,2,_]
  • 解释: 函数应该返回新的长度 2 ，并且原数组 nums 的前两个元素被修改为 1, 2 。不需要考虑数组中超出新长度后面的元素。

示例 2:

  • 输入: nums = [0,0,1,1,1,2,2,3,3,4]
  • 输出: 5, nums = [0,1,2,3,4,_,_,_,_,_]
  • 解释: 函数应该返回新的长度 5 ， 并且原数组 nums 的前五个元素被修改为 0, 1, 2, 3, 4 。

提示:

  • 1 <= nums.length <= 3 * 10^4
  • -100 <= nums[i] <= 100
  • nums 已按 非递减 顺序排列。

题解

这题和上一题有点像，评测同样只关心数组前面那段有效部分；但它多了一个很关键的条件：数组本身已经有序，而且去重之后还要保持原来的相对顺序。正因为有序，相同元素一定是挨在一起出现的，所以这题不需要真的把中间某些位置“删掉”，只需要在每一段重复元素里保留第一个，再把结果写回数组前面。

这样一来，双指针的写法就很直接了。fast 从左到右扫描数组，负责寻找新的元素；slow 留在已经去重好的那段有效区间末尾。只要 nums[fast] 和 nums[slow] 相同，就说明还在同一段重复元素里，直接跳过；一旦它们不同，就说明找到了一个新的值，这时先让 slow 往后走一位，再把 nums[fast] 写到 nums[slow] 上。

这里之所以能这么比较，靠的就是“有序”这个条件。如果数组不是有序的，相同元素可能散落在各个位置，你就没法只靠相邻关系做判断了；但在这题里，重复元素总是连在一起，所以只要盯住当前有效区间末尾那个值，就够了。

为什么 slow 从 0 开始、fast 从 1 开始，也和这个条件有关。题目保证数组长度至少为 1，而且第一个元素无论如何都应该保留，所以可以直接把它当成去重后结果的起点。后面从第二个元素开始扫描，看看它是不是一个新的值即可。

拿示例 2 看会更直观。nums = [0,0,1,1,1,2,2,3,3,4]，初始时 slow = 0，fast = 1。先看到第二个 0，它和 nums[slow] 相同，说明重复，跳过。等 fast 走到第一个 1 时，因为 1 != 0，说明这是一个新元素，于是先让 slow 变成 1，再把 1 写到 nums[1]。后面再遇到新的 2、3、4 时，处理方式完全一样。最后数组前面就会整理成 [0,1,2,3,4]，而这时 slow = 4，所以答案长度是 slow + 1 = 5。

也正因为 slow 表示的是“最后一个有效元素所在的位置”，不是元素个数，所以返回值要写成 slow + 1。这题很容易顺手写成 return slow;，但那样少算了第一个元素。

public int removeDuplicates(int[] nums) {
    int slow = 0;

    for (int fast = 1; fast < nums.length; fast++) {
        if (nums[fast] != nums[slow]) {
            slow++;
            nums[slow] = nums[fast];
        }
    }

    return slow + 1;
}

时间复杂度是 $O(n)$，因为整个数组只扫描了一遍；空间复杂度是 $O(1)$，只用了两个额外变量。

这题可以顺手记成一个很常见的判断：只要数组有序，相同元素就会自然聚在一起，很多原地去重问题都能变成“每一段重复元素里保留前面几个”。这一题保留的是每段里的第一个，下一题其实就是在这个基础上再往前走一步。

import java.util.Arrays;

public class Main {

    public static int removeDuplicates(int[] nums) {
        int slow = 0;

        for (int fast = 1; fast < nums.length; fast++) {
            if (nums[fast] != nums[slow]) {
                slow++;
                nums[slow] = nums[fast];
            }
        }

        return slow + 1;
    }

    public static void main(String[] args) {
        int[] nums1 = new int[]{1, 1, 2};

        System.out.println("示例 1 输入:");
        System.out.println("nums = " + Arrays.toString(nums1));

        int k1 = removeDuplicates(nums1);
        int[] result1 = Arrays.copyOfRange(nums1, 0, k1);

        System.out.println("示例 1 输出: " + k1 + ", nums = " + Arrays.toString(result1));
        System.out.println("-----------------------------");

        int[] nums2 = new int[]{0, 0, 1, 1, 1, 2, 2, 3, 3, 4};

        System.out.println("示例 2 输入:");
        System.out.println("nums = " + Arrays.toString(nums2));

        int k2 = removeDuplicates(nums2);
        int[] result2 = Arrays.copyOfRange(nums2, 0, k2);

        System.out.println("示例 2 输出: " + k2 + ", nums = " + Arrays.toString(result2));
    }
}
